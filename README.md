# Data Science & Machine Learning Projects 🚀

В данном репозитории собраны мои практические проекты в области анализа данных и компьютерного зрения.

## Структура проектов

### 1. Определение возраста по фотографии (Computer Vision)
* **Задача:** Построение модели для определения приблизительного возраста человека по фотографии для оптимизации ассортимента супермаркета.
* **Стек:** Python, PyTorch / TensorFlow (Keras), ResNet, PIL, Pandas.
* **Результат:** Обучена сверточная нейросеть, достигнуто целевое значение метрики качества MAE < 8 лет.

### 2. Анализ продаж компьютерных игр для интернет-магазина (EDA)
* **Задача:** Выявление закономерностей, определяющих успешность игр, для планирования рекламных кампаний интернет-магазина.
* **Стек:** Python, Pandas, NumPy, Matplotlib, Seaborn, Сhie-square test.
* **Результат:** Проведен полный исследовательский анализ данных (EDA), составлены портреты пользователей разных регионов и проверены статистические гипотезы.

### 3. Исследование объявлений о продаже квартир (Data Analytics)
* **Задача:** Определение рыночной стоимости объектов недвижимости и выявление факторов, влияющих на цену квартир.
* **Стек:** Python, Pandas, Matplotlib, обработка пропусков и аномалий.
* **Результат:** Установлены зависимости цены от площади, числа комнат и удаленности от центра. Построены графики распределения параметров.
