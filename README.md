## Project Overview

### 1. Age Estimation via Photographs (Computer Vision)
* **Objective:** Develop a model to estimate a person's approximate age from a photograph to optimize product assortments in a supermarket.
* **Stack:** Python, PyTorch / TensorFlow (Keras), ResNet, PIL, Pandas.
* **Result:** Trained a convolutional neural network (CNN), achieving the target quality metric of MAE < 8 years.

### 2. Video Game Sales Analysis for an Online Store (EDA)
* **Objective:** Identify underlying patterns that determine video game success to effectively plan marketing campaigns for an online retailer.
* **Stack:** Python, Pandas, NumPy, Matplotlib, Seaborn, Chi-square test.
* **Result:** Conducted a comprehensive exploratory data analysis (EDA), constructed distinct user profiles for different geographical regions, and performed statistical hypothesis testing.

### 3. Real Estate Listings Analysis (Data Analytics)
* **Objective:** Determine the market value of real estate properties and isolate key factors that influence apartment pricing.
* **Stack:** Python, Pandas, Matplotlib, missing value handling, anomaly detection.
* **Result:** Established correlations between property price and parameters such as total area, number of rooms, and proximity to the city center. Built comprehensive parameter distribution plots.
